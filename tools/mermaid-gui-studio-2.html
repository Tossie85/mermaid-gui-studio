保存・読み込み機能について

保存（エクスポート）

コードをコピー
現在のMermaidコードをそのままクリップボードにコピーします。
Markdownとしてコピー
```mermaid で囲んだ形でコピーします。GitHubやNotion、Wikiなど、Mermaid対応のMarkdownにそのまま貼り付けられます。
.md 保存
「Markdownとしてコピー」と同じ内容をファイルとしてダウンロードします。共有や他ツールへの受け渡しに向いています（GUIの構造データは含みません）。
.svg 保存
現在プレビュー表示されている図を、画像（SVGファイル）として保存します。資料やスライドへの貼り付け用です。
.html 保存
この図単体を、ブラウザでそのまま開ける単独HTMLファイルとして保存します。Mermaid.js本体を埋め込んでいるため、インターネット接続がない環境でも表示できます。
🗂️ プロジェクト保存
ノード・エッジ・色などGUIの全データをJSON化し、改ざん検知用のハッシュ値（SHA-256）と一緒に .md ファイルへ埋め込んで保存します。
このツールで再度開くと、GUIの編集状態を完全に復元できます。通常のMarkdownとしても開けるよう、```mermaidブロックも一緒に出力されます。

読み込み（インポート）

⬇️ コードをGUIに取り込む
下のコード欄にあるMermaidコードを解析し、GUIのフォームに載せ直します。他所で書いたコードやAIに生成させたコードを貼り付けて、続きをGUIで編集できます。
📂 ファイルを開く
選択したファイルの内容に応じて、自動的に次のいずれかの動作になります。
  1. 「🗂️ プロジェクト保存」で書き出したファイル → 埋め込まれたハッシュ値を検証し、一致すればGUIの編集状態を完全復元
  2. ハッシュが一致しない（手編集・改ざんの可能性）→ 安全のためコードのみを読み込み、警告を表示
  3. 通常の .md（```mermaidブロックを自動検出）や .mmd などの生コードファイル → 上の「GUIに取り込む」と同じ処理を試みます

取り込みは「全部か、ゼロか」です

ビルダーで表現できない記述が1つでもあれば、取り込み自体を中止し、何行目の何が原因かを一覧で表示します。その場合はコードのみの読み込み（「コードを直接編集する」がONの状態）になります。

中途半端に取り込むと、解釈できなかった記述が次にGUIを編集した瞬間、コード再生成で黙って消えます。それは利用者から見れば「ツールが図を壊した」ことに他ならないため、読めないものは読まない方針にしています。

取り込めない代表的な記述は次のとおりです。

  • click、%%{init:…}%%、フロントマター（---）
  • フローチャートの classDef / class / :::（クラス定義）
    状態遷移図だけは事情が違います。Mermaidに状態の色を直接指定する書き方が無く、本ツールも classDef と class の組で色を出力しているため、この形（1つの状態に1つのクラスを割り当て、中身は塗りと枠線のみ）に限って取り込めます。
  • A & B --> C のまとめ書き、subgraph の入れ子、subgraphごとの direction
  • ビルダーに無い図形（台形など）、ハイフンを含むID
  • シーケンス図の autonumber / activate / box / rect / A->>+B の活性化指定
  • 状態遷移図の note / direction / <<fork>>・<<join>>・<<choice>> / 並行処理の区切り（--）

逆に、A --> B --> C の連鎖、A -- ラベル --> B の書き方、---> のような長さ違いの矢印、graph 始まりの旧表記は、意味が同じなので正規の形に直して取り込みます。コメント行（%%）は保持できないため、取り込む前に確認を出します。

状態遷移図では、state X { } の中に書いた遷移も取り込めますが、再生成時はブロックの外にまとめて出力されます（Mermaidとしての意味は同じです）。

取り込みは一方向です。取り込んだ後はGUI側が正となり、コードはGUIから再生成されます。

GUIに取り込めませんでした
このツールについて

Mermaid GUI Studio 2

Mermaidのフローチャート・シーケンス図・状態遷移図をGUIで組み立てられるツールです。既存のMermaidコードをGUIへ取り込む機能を備えています。ブラウザ単体で動作し、外部サーバーへの通信は行いません。
